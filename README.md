# money

スクショの明細から文字を抽出し、APIキーなしのAIで登録しやすいテキストに整理してから保存できるReactアプリです。

## 始め方

```bash
npm install
npm run dev
```

画像から文字を抜くOCRは無料でブラウザ内で動きます。テキスト整理にはPuter.jsのAIを使うので、Googleのプロジェクト作成やAPIキー登録はいりません。

## 使い方

1. 初回起動で名前、暗証番号、銀行残高、給料日、予算、カード情報を入れる
2. 次回から暗証番号でログイン
3. 明細スクショを選ぶ
4. AIが整えたテキストを修正
5. 明細に変換
6. 登録候補を確認
7. 確認して登録

複数カードの引き落とし予定も、カード名、引き落とし日、予定額ごとに管理できます。
締め日やメモも入れられるので、楽天、EPOS、UFJ系カードなどを分けて見られます。

ログインはこのアプリ内だけの簡易ロックです。本格的なユーザー認証ではありません。

読み取ったテキストはこの形にすると登録できます。

```txt
2026-09-03 | カード | カード | 120000
2026-08-30 | 支出 | STARBUCK | 1000
2026-08-25 | 収入 | 給料 | 14901
```
